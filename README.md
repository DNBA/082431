# ToeicQuest 整理版

## Season Journey 核心賽季版

- 82 場例行賽改為逐場推進，每場分成 1Q、2Q、3Q、4Q／延長賽。
- 賽季體力以籃球表示：基準上限 15；低於 15 時每 30 分鐘恢復 1 球，任務獎勵可以超過 15。
- 每個單項每日任務額外獎勵 1 球，三項全解再獎勵 2 球。
- 支援自訂球隊名稱、Game Day 特殊節點、逐節播報、快速模擬與 Badge Moment 漫畫。
- 第一版榮譽卡背為 Champion、FMVP、MVP、DPOY、Record Breaker、Franchise Legend。
- Franchise Legend 條件：同一卡片效力 8 季、出賽 400 場、至少 1 冠及 1 項重大榮譽。
- 管理員模式擁有無限體力，可指定模擬到 Game 1–82、一鍵完成例行賽／奪冠測試及預覽全部卡背。
- 掛機模式會依正常速度自動進行指定場數，最多不能超過現有體力或剩餘賽程；Badge Moment 會自動翻頁。
- 一輪 10 題的單字測驗達成 10/10 時，立即額外獲得 1 顆體力球。
- 目前 11 類徽章各有 3 種突發故事，共 33 種；每場最多觸發一次。
- 特殊賽事已接入逐場流程：Opening Night、Rivalry、Christmas、All-Star、Trade Deadline、Playoff Race、Must Win 與 Finale；Game 81 會優先判斷 Must Win。
- 選擇榮譽卡背後，卡庫與先發／替補卡片背景會同步更新；升星會繼承並合併卡背、Moment、熟練度與生涯資料。
- Badge Moment 會顯示實際觸發球員照片，掛機時仍會自動逐頁播放。
- 每場 Box Score 會重新計算士氣：火熱 OVR +1、普通不變、低迷 OVR -1；只影響下一場，不修改永久卡片 OVR。

這個資料夾是一份不影響桌面原檔的整理版。請保留整個資料夾，不要只單獨移動 `index.html`。

## 怎麼開啟

1. 進入 `ToeicQuest` 資料夾。
2. 雙擊 `index.html`。
3. 瀏覽器會讀取同資料夾內的 CSS、JavaScript 與單字資料。

如果頁面沒有樣式或單字庫顯示未載入，通常是某個子資料夾被移走。請確認 `css`、`data`、`js` 都和 `index.html` 放在一起。

## 以後怎麼請 Codex 修改

直接描述「哪個功能、目前發生什麼、希望變成什麼」。例如：

- 請修改 `ToeicQuest/js/app.js` 的單字功能：刪除單字後希望可以復原。
- 請調整 `ToeicQuest/css/styles.css`：手機上的底部選單太高。
- 請修改抽卡功能：十連抽至少保證一張 SR。
- 請先找出球季模擬功能在哪裡，不要修改，先告訴我設計方式。

不需要知道程式行號，也不用自己找函式名稱。

## 檔案用途

- `index.html`：畫面結構，已從約 800 KB 降到約 118 KB。
- `css/styles.css`：網站樣式與動畫。
- `data/toeic1000.js`：多益單字資料。
- `js/app.js`：目前主要功能程式。
- `js/bootstrap.js`：頁面載入完成後的初始化處理。
- `ARCHITECTURE.md`：拆分方式與後續整理規劃。

## 本次已修正

- 通知中心同時支援兩種呼叫格式，避免顯示 `[object Object]`。
- 補上刪除單字功能與刪除前確認視窗。
- CSS、單字資料及 JavaScript 已從 `index.html` 抽離。
- 新增獨立「卡庫」頁籤，球員卡片庫不再和陣容擠在同一頁。
- 重做手機卡庫版面：工具列兩欄排列、卡片自適應 2～5 欄，並避免水平溢出。
- 單字測驗、三分球大賽與禮包兌換碼視窗改為螢幕中央顯示。
- 單字卡補回不依賴圖示套件的「🔊 發音」按鈕，測驗題目也可直接朗讀。
- 新增可保存的錯題複習本：答錯自動收藏，可一鍵專練錯題；連續答對兩次才會畢業。
- 答題後會顯示正確答案及例句，錯題停留時間較長，方便閱讀與記憶。

## 修改時的安全做法

每次修改前先複製整個 `ToeicQuest` 資料夾作為備份。完成後至少檢查：頁面能開啟、舊存檔能讀取、瀏覽器主控台沒有紅色錯誤。
